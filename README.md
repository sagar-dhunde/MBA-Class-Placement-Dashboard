# 🎓 MBA Class Placement Dashboard

An interactive Power BI project designed to track, analyze, and visualize placement trends, recruitment statistics, and key career facts for MBA cohorts.

---

## 📊 Project Overview

This dashboard bridges the gap between complex recruitment data and institutional decision-making. It provides an intuitive layout and engaging visualizations to explore core placement dimensions, including:

* **Placement Trends:** Monitor overall placement percentages, job offer volumes, and hiring rates across graduating batches.
* **Compensation Analysis:** Track salary packages, average/median CTCs, and financial distributions across specializations.
* **Recruiter Insights:** Identify top hiring companies, favored industry sectors, and recurring recruiting partners.
* **Student Demographics:** Analyze student profiles, prior work experience brackets, and academic backgrounds against career outcomes.

---

## 📁 Repository Structure

* `placement dashboard.pbix` - The primary Power BI source file containing the data model, DAX measures, and dashboard layouts.
* `Placement Dashboard.png` - A preview image showcasing the dashboard's design and final visualizations.

---

## 🛠️ Tools & Technologies Used

* **Power BI:** Data transformation (Power Query), data modeling, DAX calculations, and interactive visualization.
* **Microsoft Excel / CSV:** Initial data staging and preparation source.
